# My Orders App 📦

A modern Android Native UI implementation of the **“My Orders”** screen created as part of the Mobile Application Developer Internship assignment for :contentReference[oaicite:0]{index=0}.

---

##  Project Overview

This project demonstrates a clean and responsive Android UI built using:

- Kotlin + XML
- RecyclerView
- Material Design Components
- Bottom Navigation
- Custom Tabs & Buttons
- Native Android Development

The design closely follows the provided reference UI with proper spacing, alignment, click effects, and responsive layouts.

---

##  Features

- Modern Orders Listing UI
- RecyclerView-based Order Cards
- Bottom Navigation Menu
- Search, Filter & Sort UI
- Responsive Layout Design
- Custom Drawable Backgrounds
- Click Effects for Tabs & Buttons
- Clean Architecture & Folder Structure
